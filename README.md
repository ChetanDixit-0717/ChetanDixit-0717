### 1. AANCHAL

**AI-Assisted Nutrition & Child Health Awareness Layer** · 🚧 *Ongoing project*

An AI-powered child nutrition awareness application designed for the **Anganwadi community**. It reads nutrition labels from images and uses an LLM to turn the extracted data into clear nutrition analysis.

| | |
|:--|:--|
| **Implemented** | • OCR-based nutrition label extraction<br/>• Image preprocessing and text recognition<br/>• Nutrition information extraction<br/>• LLM-powered nutrition analysis using Groq<br/>• LangChain prompt engineering<br/>• OCR confidence scoring and manual review indicators |
| **In development** | • Nutrition awareness chatbot<br/>• Retrieval-Augmented Generation (RAG)<br/>• Verified nutrition knowledge retrieval |
